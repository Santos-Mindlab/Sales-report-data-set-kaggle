# Sales-report-data-set-kaggle


## 📝 Project Description
This repository contains an in-depth analysis of a sales report, using a dataset downloaded from **Kaggle**. The project aims to extract business insights and visualize sales trends in a clear and interactive way.

## 📂 Repository Contents
Inside this folder, you will find all the necessary elements to reproduce the analysis and the application:
* **Analysis Scripts:** The files and notebooks used for exploring, cleaning, and analyzing the dataset.
* **Streamlit App:** The source files to generate the web interface and display the results using Streamlit.
* **Configuration:** The `requirements.txt` file containing the essential libraries to run the code.
*  ** Dataset:** The file .csv taht is used
